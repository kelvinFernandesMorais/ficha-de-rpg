# ficha-de-rpg
# 🎲 Criador e Gerenciador de Fichas de RPG

## 📌 O Projeto
Um site que cria e armazena sua ficha de RPG.

## 💡 Por que escolhi esse projeto?
Pois é algo que será de extrema utilidade para mim e para meus amigos, já que é usado um sistema próprio.

## 🎯 Qual o objetivo do site?
Ao ser finalizado, ele deve criar a ficha de personagem, deixando escolher:
* Atributos
* Classes
* Personalidade base
* Perícias

Após isso, ele irá armazenar as informações e retornar com a ficha. 

Após a criação da ficha, o site deve apresentar:
* Estatísticas de **Vida**, **Sanidade** e **Pontos de Potencial**
* **Nível** e **CP**
* **Habilidades**
* **Inventário**
